# ADR-0099: 雛形の名前の付け替えはスクリプト 1 本で行う

- 日付: 2026-10-31
- 状態: 承認

## 文脈

派生アプリを作るときの名前の付け替えは手作業で、ファイルの一覧を見て直していた（`docs/TEMPLATE.md` 2.2）。間違えても自動では止まらない（ADR-0073 §1。task #800）。

## 決定

1. **`scripts/rename_project.sh <new-name>` を置く。** 追跡しているファイルの中の雛形の名前を、大文字小文字を問わず全部置き換える。一覧を持たない。
2. **`docs/CHANGELOG.md` と `docs/decisions/` は置き換えない。** 雛形の履歴と決定の記録で、書き換えると嘘になる。`uv.lock` と `package-lock.json` は置き換える（名前が食い違うと `uv sync --frozen` の前提が崩れる）。
3. **名前は `^[a-z][a-z0-9]*(-[a-z0-9]+)*$` で 40 文字まで。** namespace・イメージ名・`pyproject.toml` のすべてに使える形だけを通す。
4. **コミットしていない変更があれば断る。** スクリプトはコミットしない（`git diff` で見て、`git checkout .` で戻せる）。
5. **雛形の remote（`template`）をスクリプトが足す。** 置き換えると文書から元の URL が消えるため。
6. スクリプト・試験・確かめのコマンドの名前には `[t]` を挟む（`fastapi[t]emplate`）。自分自身が置き換えられず、確かめにも引っかからない。

## 理由

- 一覧を持つと、名前が増えたときに一覧が古くなる。全部置き換えて確かめるほうが漏れない。

| 採らなかった案 | 捨てた理由 |
|---|---|
| Cookiecutter や Copier で雛形にする | 雛形のリポジトリそのものが動かなくなり、更新の取り込み（`docs/TEMPLATE.md` 5 章）の `git merge` も使えない |
| deck のプロジェクト作成だけで付け替える | 手で作る道が残る。deck もこのスクリプトを呼べる |
| 小文字だけを置き換える | `TOTP_ISSUER` などの表示名の書き方が変わると漏れる |

## 影響

- 付け替えたあとの文書の文面は機械的な置き換えなので、`README.md` は書き直す（`docs/TEMPLATE.md` 2.4）。
- GNU sed を前提にする（手元の環境とコンテナが Linux のため）。

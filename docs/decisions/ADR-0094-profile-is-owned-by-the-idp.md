# ADR-0094: IdP と結び付いている利用者の名前とメールは、IdP でだけ直す

- 日付: 2026-10-31
- 状態: 承認
- 置き換える節: ADR-0080 §3 決定 2 の「メールアドレス・表示名は本人が変更できる」（IdP と結び付いている利用者について）

## 文脈

ADR-0077 §6 で、名前とメールの写しはログインのたびに IdP の値で上書きする。結び付いている利用者が画面で直しても、次のログインで黙って戻る（task #795）。

## 決定

1. **結び付きのある利用者（`federated_identities` に行がある人）は、名前とメールを `PUT /api/auth/me` で変えられない。** 変えようとすると 403 `profile_managed_by_idp`。今の値と同じなら成功として何もしない。
2. **判定は今どの入口で入ったかではなく、結び付きの有無で行う。** パスワードで入っていても、結び付いていれば次の SSO で上書きされるため。
3. **`GET /api/auth/me` に `profile_managed_by_idp` を載せ**、プロフィールの画面は入力欄を出さず、値と案内だけを出す。連携を外せば（ADR-0077 §5）今までどおり直せる。

## 理由

- 保存できたように見えて戻るのが一番分かりにくい。先に断れば、直す場所が 1 つに決まる。

| 採らなかった案 | 捨てた理由 |
|---|---|
| 画面の入力欄だけ外す | API を直に叩く人や古い画面では今までどおり黙って戻る |
| 上書きをやめて、こちらの値を優先する | ADR-0077 §6 の「IdP が正」が崩れ、IdP で直した名前が届かなくなる |
| SSO で入っているときだけ断る | パスワードで入れば直せてしまい、次の SSO で戻る |

## 影響

- 管理者が管理画面で利用者の名前やメールを直す口はこの決定の外で、次のログインで上書きされるのは今までと同じ。
- ⚠ 派生アプリは取り込むと同じ挙動になる。SSO を使っていないアプリは結び付きが無いので変わらない。

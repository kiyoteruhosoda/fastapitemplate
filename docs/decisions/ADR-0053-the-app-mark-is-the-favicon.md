# ADR-0053: 画面の中のアプリの像は favicon.svg をそのまま使う

- 日付: 2026-10-07
- 状態: 承認

## 文脈

タブ・ホーム画面のアイコンは `scripts/generate_pwa_icons.py` 1 本から作っている。テンプレートから
作ったアプリ（WBS）は、ログイン画面とメニューの上に別の絵（画面のコードに書いたチェックマーク）を
置いていて、タブのアイコンと違って見えた。図柄を変えるたびに画面側の直しが漏れる。

## 決定

画面の中の像は部品 `AppMark`（`frontend/src/components/AppMark.tsx`）に寄せ、絵は持たずに
`favicon.svg` を `<img>` で読む。ヘッダーとサインイン前の画面（ログイン・パスワード再設定）に出す。

## 理由

- 正本が生成スクリプト 1 本になり、図柄や色を変えると全部の場所がいっしょに変わる。
- favicon はベクタ（SVG）なので、28px のヘッダーでも 44px の見出しでもそのまま縮められる。
  角丸と地の色も絵の側に入っているので、画面側で箱を描き直す必要もない。
- 採らなかった案: 図柄を React の部品として書き、生成スクリプトがそれを読む形。正本が TS と
  Python の 2 か所に割れる。タブとホーム画面のアイコンは生成物である以上、画面がそれを読むほうが短い。

## 影響

- 派生アプリで像を足す場所が増えても、絵を書き起こさず `AppMark` を使う。
- 画面の像だけを違う絵にすることはできない（したいなら、それは別の決定として ADR を書く）。

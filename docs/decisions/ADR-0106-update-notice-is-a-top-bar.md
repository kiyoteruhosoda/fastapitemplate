# ADR-0106: 新しい版の知らせは、どの画面でもいちばん上の帯にする

- 日付: 2026-11-09
- 状態: 承認（ADR-0080 §7 決定 1 の「画面の下に出す」を置き換える）

## 文脈

新しい版が待機すると「新しい版があります [再読み込み]」を出す（ADR-0080 §7）。これまでは画面の下の中央に
浮かべていたが、本文やトーストに紛れて目立たず、持ち主から「一番上にして目立つようにしたい。ポップアップでなく
ヘッダーに出したい」と言われた。

ヘッダーはサインイン後の外枠（`AppLayout`）にしか無く、ログイン画面・パスワードの再設定・SSO の戻り・
2 段階認証の登録には無い。ヘッダーの中に置くと、それらの画面では知らせが出ない。

## 決定

1. 知らせは**画面のいちばん上に、横幅いっぱいの帯で**出す。アクセント色の地にし、ボタンは色を反転させる。
   押されるまで消さない（ADR-0080 §7 のまま）。
2. 帯は `main.tsx` で画面（`<App />`）より前に置き、**どの画面にも**出す。`position: sticky; top: 0` で、
   下へ送っても上に残す。
3. サインイン後の画面では、ヘッダーが帯の**真下に**貼り付く。帯は自分の高さを `<html>` の CSS 変数
   `--update-bar-height` で渡し（狭い画面で折り返すと高さが変わるので `ResizeObserver` で見張る）、
   `.header` は `top: var(--update-bar-height, 0px)` に貼り付く。帯が消えたら変数を外す。
4. 狭い画面のドロワー（z-index 30）は帯（28）の上に開く。開いている間はドロワーだけを操作させるため（ADR-0080 §2）。

## 理由

- **ヘッダーの中に入れない。** ヘッダーの無い画面で出なくなる。帯をヘッダーの上の別の段にすれば、
  ヘッダーのある画面ではヘッダーと一体に見え、無い画面でも同じ位置に出る。
- **固定（`position: fixed`）にしない。** 本文の上に重なり、ヘッダーや本文の先頭を隠す。sticky なら場所を取るので
  何も隠さない。
- **ヘッダーの位置を変数で渡す。** 帯とヘッダーを 1 つの箱に入れて貼り付ければ変数は要らないが、帯は
  ルーターの外（どの画面でも出すため）、ヘッダーは `AppLayout` の中にあり、同じ箱に入れられない。
- 画面の下に浮かべる形（従来）は、目に入る位置ではなく、トーストとも重なった。

## 影響

- ⚠ **貼り付く要素（`position: sticky; top: …`）を足すときは、`top` に `var(--update-bar-height, 0px)` を足す。**
  足さないと、知らせが出ている間その要素が帯の下に潜る。
- 派生アプリは取り込むまで従来の形のまま。取り込むときは自前の sticky 要素を上のとおり直す。

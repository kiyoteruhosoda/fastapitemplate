# ADR-0096: 未認証の /info は残し、版だけを返す

- 日付: 2026-10-31
- 状態: 承認

## 文脈

`/info` は未認証で版・git SHA・枝・ビルド時刻・環境名を返す（`/metrics` は task #736 で閉じた）。閉じるか残すかを、読んでいるものを確かめて決める（task #797）。

2026-10-31 に確かめた読み手:

| 読み手 | 読むもの | 確かめた場所 |
|---|---|---|
| 画面のフッター | `version` | `frontend/src/components/Footer.tsx` |
| 配ったあとの版の確かめ（人と Claude。Renovate の定期掃除も） | `git_sha`（`version`） | deploy-repo `host/renovate-sweep/prompt.md`・`docs/OPERATIONS.md` |
| deck | **読んでいない。** deck が読むのは自分の `/info` を自分の画面からだけで、配った先の版は k8s の像で確かめる | nolumiadeck の `/info` と `git_sha` の全文検索 |
| 監視（ホストの見張り・deploy-repo の `host/`）・Pod の生死確認 | 読んでいない。Pod の確認は `/healthz` | deploy-repo の全文検索・`k8s/*/40-app.yaml` |

## 決定

1. **`/info` は未認証のまま残し、`version` と `git_sha` だけを返す。** 枝・ビルド時刻・環境名は外す。
2. 外した 3 つは `/api/admin/system`（`system:view`）で読む（今もある）。
3. 公開の一覧（`test_route_authorization.py` の `_PUBLIC_ROUTES`）に残し、応答の項目は `test_health.py` で固定する。

## 理由

- **閉じない**: 配ったあとの確かめが、権限の無い機械とログインの要らない確かめで回っている（本番を起こさずに「この版が動いている」と言える唯一の口）。
- **項目を絞る**: 読み手が使うのは版だけ。枝は作業中の名前を漏らし、ビルド時刻は攻撃者に更新の周期を教え、環境名は本番の見分けを教える。
- **git SHA は残す**: 非公開のリポジトリでは、版の名前以上のことを教えない（`version` も同じ短縮 SHA である）。deck の ADR-0047 と同じ判断で、形も揃う。

| 採らなかった案 | 捨てた理由 |
|---|---|
| 外から 404 にする（nginx で閉じる） | 配ったあとの確かめが中からしかできなくなる。画面のフッターも読めなくなる |
| 認証を求める | フッターは入れるが、機械の確かめに資格情報を配ることになる |
| そのまま残す | 使っていない 3 項目を未認証で出し続ける理由が無い |

## 影響

- `/info` の項目が 3 つ減る。読み手で使っているものは無い。
- 公開のリポジトリから派生したアプリは、SHA で正確な版が分かる。気にするなら `version` と `git_sha` も `/api/admin/system` へ移して、確かめは Pod の中で行う。
